# 🐾 Dashboard de Vendas - Pet Shop

## 📊 Sobre o projeto

Dashboard desenvolvido no Power BI para análise de vendas de um Pet Shop.

O projeto apresenta indicadores e visualizações para acompanhamento do
faturamento, quantidade de vendas e perfil dos clientes.

## 🎯 Objetivo

Criar um dashboard interativo que permita analisar o desempenho das vendas
e identificar diferentes características dos dados.

## 📈 Indicadores

- Faturamento total
- Média de pets
- Quantidade de vendas
- Valor médio por produto

## 🔎 Análises

- Faturamento por gênero
- Faturamento por bairro
- Faturamento ao longo do tempo
- Faturamento por estado civil
- Filtros por período e marca

## 🛠️ Ferramentas

- Power BI
- DAX
- Power Query
